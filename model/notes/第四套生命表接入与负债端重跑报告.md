# 第四套生命表接入与负债端重跑报告

本文档记录将负债端模型的数据源从原先的平替生命表切换为《中国人身保险业经验生命表（2025）》养老类业务表（CL1）后的处理过程、模型调整和重跑结果。

## 1. 本次使用的数据源

原始文件：

```text
【2025】金规〔2025〕21号 - 附件：中国人身保险业经验生命表（2025）.docx
【2025】金规〔2025〕21号 - 关于做好《中国人身保险业经验生命表（2025）》发布使用有关事项的通知.pdf
```

其中，负债端模型采用 docx 附件中的第一张表：

```text
养老类业务表男女表（CL1）
```

该表的死亡率单位为：

```text
1 / 1000
```

因此抽取时进行单位换算：

```text
qx = 表格数值 / 1000
```

例如：

```text
70岁男性：10.060 / 1000 = 0.010060
70岁女性：4.958 / 1000 = 0.004958
```

## 2. 新增的数据抽取脚本

新增脚本：

```text
extract_official_life_table_2025.py
```

该脚本完成以下工作：

1. 在当前目录中定位 2025 生命表 docx 文件
2. 读取 docx 中第一张表，即 CL1 养老类业务表男女表
3. 抽取 0-105 岁男性、女性死亡率
4. 将表格单位从 `1/1000` 转换为小数形式 `qx`
5. 计算 `px = 1 - qx`
6. 按 100000 人基数计算 `lx`、`dx`
7. 计算近似剩余预期寿命 `ex`
8. 生成基准死亡率和 15% 死亡率改善两个情景

输出文件：

```text
official_cl1_life_table_2025.csv
official_cl1_life_table_2025.xlsx
```

生成后的生命表结构为：

| 字段 | 含义 |
| --- | --- |
| `sex` | Male / Female |
| `age` | 年龄，0-105 岁 |
| `qx` | 年度死亡概率 |
| `px` | 年度生存概率 |
| `lx` | 年龄 x 的生存人数 |
| `dx` | 年龄 x 到 x+1 岁之间死亡人数 |
| `ex` | 近似剩余预期寿命 |
| `mortality_improvement` | 死亡率改善情景 |

最终生成：

```text
424 行 = 2 个性别 * 106 个年龄 * 2 个死亡率情景
```

## 4. 模型代码调整

### 4.1 默认生命表切换

`liability_model.py` 中默认数据源已从：

```text
synthetic_life_table_for_codex.csv
```

切换为：

```text
official_cl1_life_table_2025.csv
```

即后续直接运行模型时，默认使用第四套生命表 CL1 数据。

### 4.2 终端年龄月度处理修正

原模型将年度死亡概率转为月度死亡概率：

```text
q_month = 1 - (1 - qx)^(1/12)
```

但当 `qx = 1` 时，直接套用该公式会得到：

```text
q_month = 1
```

这会导致所有到达 105 岁的路径在第一个月立即死亡，和生命表中 105 到 106 岁之间死亡的年区间口径不完全一致。

因此模型已修正为：

```text
若 qx < 1:
    q_month = 1 - (1 - qx)^(1/12)

若 qx = 1:
    将死亡均匀分布到终端年龄的 12 个月内
```

这样 105 岁的剩余预期寿命约为 0.5 年，与 `ex = 0.5` 的生命表口径一致。

## 6. 模型公式口径

### 6.1 死亡概率

年度死亡概率转月度死亡概率：

```text
q_month(x) = 1 - (1 - qx)^(1/12)
```

终端年龄 `qx = 1` 时，死亡均匀分布于 12 个月。

### 6.2 房产价值

房价服从几何布朗运动：

```text
dH_t / H_t = (r_t - q)dt + sigma_H dW_t^H
```

离散化：

```text
H_t = H_{t-1} * exp((r_t - q - 0.5 * sigma_H^2)dt + sigma_H * sqrt(dt) * Z_t)
```

### 6.3 债务余额

养老金债务按月累积：

```text
D_t = D_{t-1} * (1 + i_t) + draw_t
```

其中：

```text
i_t = (1 + r_t + c)^(1/12) - 1
```

### 6.4 单向棘轮授信额度

```text
L_0 = LTV * H_0
L_t = min(L_{t-1}, LTV * H_t)
```

当月实际提款：

```text
draw_t = min(PMT, max(L_t - D_t, 0))
```

若 `draw_t < PMT`，则记录为提款截断。

### 6.5 清算与担保不足损失

房产净变现价值：

```text
V_T = H_T * (1 - delta)
```

担保不足损失：

```text
shortfall_T = max(D_T - V_T, 0)
```

继承人剩余权益：

```text
bequest_T = max(V_T - D_T, 0)
```

### 6.6 双重风险约束

当前反解最高月领金额时采用双重约束：

```text
P95(shortfall_T) / H_0 <= 1%
stopped_draw_probability <= 5%
```

第一条控制机构端尾部亏损，第二条控制老人端养老金被截断的概率。

## 8. 结果解释

### 8.1 黄浦场景仍然最稳健

在双重约束下，最高可支付月领金额最高的是：

```text
huangpu_small / Male / mortality_improvement = 0
月领金额约 5187 元
```

黄浦老破小的初始房产价值高、波动率较低，因此资产端对负债端的支撑能力最强。

### 8.2 金山场景约束最强

最低的是：

```text
jinshan_small / Female / mortality_improvement = 0.15
月领金额约 568 元
```

原因是金山场景初始房产价值仅 98 万元，虽然房价波动率不高，但资产底盘太小，无法长期支持高额养老金。

### 8.3 固定月领 8000 元在多数场景下不可持续

固定月领 8000 元时：

- 黄浦短缺概率较低，但提款截断概率已经达到 30%-48%
- 闵行短缺概率达到约 7.68%-12.21%，截断概率达到 65%-79%
- 金山短缺概率达到约 25.43%-38.17%，截断概率高达 95% 左右

这说明在加入单向棘轮风控后，固定 8000 元的名义养老金在多数非核心房产场景中难以持续。

### 8.4 长寿压力会降低月领金额

将 `mortality_improvement` 从 0 提高到 0.15 后，死亡率下降、寿命延长，养老金支付期变长，负债压力上升，因此多数场景下反解月领金额下降。

例如：

```text
huangpu_small / Male:
基准死亡率：5187 元
长寿压力：4774 元
```

```text
minhang_mid / Male:
基准死亡率：1919 元
长寿压力：1693 元
```

## 11. 可写入论文的表述

本文负债端采用《中国人身保险业经验生命表（2025）》中养老类业务表男女表（CL1）作为死亡率基础。由于原表死亡率单位为 `1/1000`，本文将其转换为年度死亡概率 `qx`，并进一步折算为月度死亡概率以匹配养老金按月支付的现金流结构。模型以生命表生成随机死亡时点，以几何布朗运动模拟房产价值，以 CIR 模型刻画短端利率波动，并通过单向棘轮机制限制房价下跌时的后续提款额度。

在非追索权信托结构下，清算时若债务余额超过房产净变现价值，其差额即为担保不足损失。本文以 `shortfall = max(D_T - V_T, 0)` 度量风险补偿基金的潜在赔付压力，并在反解月度养老金时同时约束 `P95(shortfall) / H_0 <= 1%` 和提款截断概率不超过 5%。基于官方 CL1 表的仿真结果显示，核心区高价值房产具有更强的养老金承载能力，而远郊低价值房产在长寿压力情景下可支付月领金额显著下降。
