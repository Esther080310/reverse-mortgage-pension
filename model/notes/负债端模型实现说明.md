# 负债端模型实现说明

本实现文件为 `liability_model.py`，用于把生命表接入“信托以房养老”负债端，完成死亡时间、养老金债务余额、房产清算价值、担保不足损失和风险补偿基金费率的蒙特卡洛测算。

## 1. 数据输入

当前默认读取：

```text
official_cl1_life_table_2025.csv
```

生命表字段沿用现有说明：

- `sex`: Male / Female
- `age`: 年龄，50-110 岁
- `qx`: 年龄 x 到 x+1 岁之间死亡概率
- `px`: 年龄 x 到 x+1 岁之间生存概率
- `mortality_improvement`: 死亡率改善情景，0 为基准，0.15 表示 qx 下调 15%

该文件由 `extract_official_life_table_2025.py` 从《中国人身保险业经验生命表（2025）》docx 附件中的“养老类业务表男女表（CL1）”抽取得到。原表死亡率单位为 `1/1000`，脚本已统一转换为小数形式 `qx`。

旧的 `synthetic_life_table_for_codex.csv` 是前期开发使用的 CL1 风格平替表，目前不再作为默认数据源。

## 2. 核心建模逻辑

### 2.1 长寿风险

年死亡概率 `qx` 被转换为月度死亡概率：

```text
q_month = 1 - (1 - qx)^(1/12)
```

每条路径逐月抽样死亡事件。若到生命表终点仍未死亡，则在最高年龄强制清算，避免尾部路径无限延伸。

### 2.2 债务余额

每月债务先按利率和运营成本累积，再支付当月养老金：

```text
D_t = D_{t-1} * (1 + r_month + c_month) + draw_t
```

其中 `draw_t` 受动态授信额度约束。默认启用单向棘轮机制。

### 2.3 房产价值

房产价值按几何布朗运动模拟：

```text
dH / H = (r_t - q) dt + sigma_H dW
```

其中：

- `r_t`: CIR 短端利率路径
- `q`: 租售比/连续分红率
- `sigma_H`: 房价年化波动率

### 2.4 单向棘轮风控

授信额度随房价评估下降而下调，但不随房价上涨而上调：

```text
L_t = min(L_{t-1}, LTV * H_t)
```

如果养老金支付会突破授信额度，则当月提款被截断，并记录为 `stopped_draw=True`。

### 2.5 担保不足损失

死亡或终点清算时：

```text
net_house_value = house_value * (1 - liquidity_discount)
shortfall = max(debt_at_death - net_house_value, 0)
bequest = max(net_house_value - debt_at_death, 0)
```

风险补偿基金费率按初始房产价值归一化：

```text
fund_premium_rate_expected = E(shortfall) / H_0
fund_premium_rate_p95 = P95(shortfall) / H_0
```

## 3. 默认资产端分层参数

脚本内置了文档中的三个示例分层：

| segment | 含义 | 初始估值 | 波动率 | 租售比 |
| --- | --- | ---: | ---: | ---: |
| `huangpu_small` | 黄浦老破小，70 平米 | 10.1万/平米 * 70 | 11% | 1.86% |
| `minhang_mid` | 闵行改善型，110 平米 | 4.9万/平米 * 110 | 13% | 1.88% |
| `jinshan_small` | 金山老破小，70 平米 | 1.4万/平米 * 70 | 14% | 2.39% |

其他关键默认值：

- 性别：Female
- 起始年龄：70
- 初始 LTV：50%
- 初始无风险利率：2.3%
- 年运营成本率：1.0%
- 清算流动性折价：10%
- 仿真次数：10000

## 4. 命令用法

固定月领金额，测算风险：

```powershell
python .\liability_model.py --segment minhang_mid --monthly-pmt 8000 --n-sims 10000 --output outputs/liability_minhang_mid_8000.csv
```

反解在“预期短缺率为 0”约束下的最高月领金额：

```powershell
python .\liability_model.py --segment huangpu_small --solve --target-shortfall-rate 0 --risk-measure expected --output outputs/liability_huangpu_solved.csv
```

反解在“95% 分位短缺不超过房价 1%”约束下的月领金额：

```powershell
python .\liability_model.py --segment minhang_mid --solve --target-shortfall-rate 0.01 --risk-measure p95 --output outputs/liability_minhang_p95_target.csv
```

使用长寿压力情景：

```powershell
python .\liability_model.py --segment minhang_mid --solve --mortality-improvement 0.15 --output outputs/liability_minhang_longevity.csv
```

## 5. 输出字段

输出 CSV 包含：

- `monthly_pmt`: 月度养老金
- `mean_death_age`, `median_death_age`, `p90_death_age`: 死亡年龄分布
- `expected_debt`: 清算时债务余额均值
- `expected_net_house_value`: 清算净房产价值均值
- `expected_shortfall`: 期望担保不足损失
- `shortfall_probability`: 发生担保不足的概率
- `shortfall_p95`: 担保不足损失 95% 分位
- `expected_bequest`: 可返还继承人的剩余净值均值
- `stopped_draw_probability`: 棘轮机制导致提款被截断的路径比例
- `fund_premium_rate_expected`: 按期望短缺计提的基金费率
- `fund_premium_rate_p95`: 按 95% 短缺计提的压力基金费率

## 6. 论文表述建议

本文负债端采用生命表驱动的随机停止时点建模方法。首先将 CL1 风格生命表中的年度死亡概率转换为月度死亡概率，逐月抽样得到老人死亡或清算时点；其次，将每月养老金提款按短端利率和运营成本进行复利累积，形成信托机构的负债余额；再次，将房产价值、利率和寿命三类风险纳入同一蒙特卡洛框架，并通过单向棘轮机制控制下行周期中的债务膨胀。最终以非追索权结构下的担保不足损失 `max(D_T - V_T, 0)` 作为风险补偿基金计提基础，同时将正向剩余净值作为继承人可返还权益。

## 7. 批量情景分析脚本

新增脚本：

```text
run_liability_scenarios.py
```

该脚本会自动运行 12 个情景：

- 三类房产：`huangpu_small`、`minhang_mid`、`jinshan_small`
- 两类性别：Male、Female
- 两类死亡率情景：0 和 0.15

每个情景输出两组结果：

1. 固定月领 8000 元的压力测试
2. 在双重约束下反解最高可支付月领金额

双重约束为：

```text
P95(shortfall) / 房产初始价值 <= 1%
stopped_draw_probability <= 5%
```

加入 `stopped_draw_probability` 约束的原因是：单向棘轮机制会在房价下跌或债务接近授信上限时截断提款。若只控制短缺风险，模型可能通过“减少后续实际支付”来压低机构风险，从而高估名义月领金额。因此，论文主口径同时约束机构端尾部风险和老人端现金流连续性。

运行命令：

```powershell
python .\run_liability_scenarios.py
```

输出文件：

```text
outputs/liability_scenario_comparison_official_cl1_2025.csv
outputs/liability_scenario_summary_official_cl1_2025.md
```
