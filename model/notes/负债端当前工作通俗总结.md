# 负债端当前工作通俗总结（保险年金模式统计精算模型）

> 2026-10-20 专业修订合并版。用通俗语言总结负债端模型已完成的工作、每一步解决了什么问题，以及现在应如何理解结果。研究原型，非任何机构现行产品或报价。

## 1. 这只是双产品中的一个

市场调查发现，老年人更偏好“现金给付+保障”的保险年金模式，中年人更偏好养老服务信托模式。本文档只总结第一种（负债端精算子模块）。

上海信托等行业机构可以帮助验证产品流程和合作方式，但模型没有假设所有钱都由信托公司出、所有风险都由信托公司承担。

## 2. 模型模拟什么

模型反复生成老人未来可能经历的路径：

```text
老人能活多久
房价未来如何变化
利率如何变化
每月发多少钱
最终债务有多少
房子清算后是否足够还债
```

清算时债务超过房产净变现价值的部分叫“担保不足损失（Shortfall）”，需要由机构或未来确定的风险承担主体承接；若卖房钱超过债务，剩余部分（Bequest）可返还继承人。

## 3. 为什么现在有两种产品责任

### 保证给付年金（主模型）

只要老人存续，每月承诺的钱就足额支付，房价下跌不能直接成为停付理由（停付概率恒为 0）。尾部损失需要由未来确定的风险承担主体承接。

### 动态调额提款（扩展模型）

合同允许在极端情况下压低授信额度，老人实际拿到的钱可能少于名义金额。这种设计对机构更灵活，但老人现金流保障更弱。

过去版本把两者混在一起，一边叫“终身固定年金”，一边允许 5% 的路径停付。修订版已经分开。

## 4. 风险指标怎么理解

| 指标 | 通俗含义 |
| --- | --- |
| 损失概率 | 有多少条路径最终出现缺口 |
| 期望损失 | 把所有路径缺口平均 |
| 条件平均损失 | 只在发生缺口的路径中平均 |
| VaR95 | 95% 路径不超过的损失水平（损失分布的 95% 分位数） |
| ES95 | 最差 5% 路径的平均损失 |

原版本把 P95 分位数写成了 Expected Shortfall，修订版已更正。**关键**：主结果中损失概率只有约 1%，低于 5%，因此 VaR95 经常为 0（旧“P95≤1%”是空约束）；但最差 5% 中仍有损失，所以 ES95 不是 0。主反解因此使用 ES95。这些指标是研究风险度量，不直接等于保费、基金费率或监管资本。

## 5. 房价为什么不用 Student-t 直接指数化

Student-t 分布没有有限矩母函数，不能直接照搬正态 GBM 的 `-0.5σ²` 补偿（否则模拟路径的期望增长与声称的漂移不一致）。修订版改成正态混合分布：

- 大多数月份处于普通波动状态；
- 5% 的月份来自三倍波动的尾部成分；
- 整体方差重新标准化为单位方差；
- 使用混合分布自己的（解析可算的）矩母函数修正指数增长。

同时保留高斯替代规格和确定性房价暴跌压力作稳健性检验。三层风控框架（基准 GBM + 分布肥尾 + 显式压力情景）不变，只是肥尾层的实现由 Student-t 换成正态混合。

## 6. 主要结果

70 岁保证给付年金的主情景（r0=1.22%、θ=2.22%、g_H^P=0%、LTV 50%）：

| 房产分层 | 月领范围 |
| --- | ---: |
| 黄浦老破小 | 2,585—3,232 元 |
| 闵行改善型 | 1,617—1,981 元 |
| 金山老破小 | 259—269 元 |

所有保证给付情景都没有停付（停付概率 0%），ES95/H0 约 0.93%—1.00%。女性、长寿压力、较高房价波动和较高成本通常会降低月领。

金山结果很低，说明低价值、高波动房产可能无法支撑有吸引力的终身保证给付，产品应考虑准入门槛、其他资金来源或不同服务结构，而不是强行提高月领。

## 7. 为什么不能只给一个精确数字

黄浦男性 65 岁，用五个随机种子重复反解：

- 月领均值约 2,331 元；
- 种子间标准差约 136 元；
- 只考虑模拟随机性的 95% 区间约 2,163—2,499 元。

但参数改变带来的差异更大：

| 假设 | 月领 |
| --- | ---: |
| 基准（11% 波动、正态混合、0% 漂移） | 2,194 元 |
| 高斯冲击、11% 波动 | 2,198 元 |
| 房价波动率 5% | 4,621 元 |
| 房价波动率 18% | 912 元 |
| 房价漂移 -1% | 1,663 元 |
| 房价漂移 +2% | 3,789 元 |

因此，大创答辩应强调“情景、区间和敏感性”，不能把某个数字说成正式报价。

## 8. 利率敏感性怎么看（修订版实验设计）

旧版把 CIR 的初始短率 r0 和长期中枢 θ 一起改却称“固定利率”，是口径混淆。修订版拆成两组实验（黄浦男 65、保证给付）：

- **仅改初始短率 r0**（θ=2.22% 固定）：月领几乎不动（约 2,198→2,189 元），因为 CIR 均值回复会把整条路径拉回 θ；
- **仅改长期中枢 θ**（r0=1.22% 固定）：月领从约 2,800 元（θ=1%）降到 1,672 元（θ=3.5%），这才是真正的敏感源。

结论：老人端对“长期利率中枢假设”敏感、对“某个时点的利率观测值”不敏感。旧版“利率 1.22%→2.22% 少领 15.9%”的表已作废。

## 9. 棘轮机制现在是什么

只用于动态调额扩展方案（保证给付年金不因授信重估而停付）。每年检查一次：

1. 债务/房价不超过 70% 时，不调整授信；
2. 超过 70% 时才允许下调；
3. 下调后不低于初始授信的 70%（保底）。

这两项（触发阈值 70%、保底 70%）已在代码实现，但都是本文设计值，需要行业访谈验证。在当前 ES95 反解出的月领水平下，开/关棘轮的反解月领几乎相同（月领较低时很少触发授信限制）；棘轮的约束力要在固定高额提款（如 8000 元）或确定性房价骤跌路径下才显现。旧版“关闭棘轮月领可升约 1,571 元”系旧约束口径产物，已作废。

## 10. 夫妻双生命

夫妻共同申办按最后生存者清算（两人都身故才能清算）。女性 68 岁 + 男性 70 岁的最后生存者合同，相比女性 70 岁单生命合同，保证给付月领平均下降约 18.1%（分区看黄浦约 −21%/−14%、闵行约 −15%/−18%、金山约 −17%/−23%，对应基准/长寿压力）。

## 11. 模型的专业亮点

- 官方 CL1 生命表和月度死亡模拟；
- 房价、利率、寿命三因素联动；
- P 测度情景而不是把风险中性关系误当现实预测；
- ES95、VaR95、损失概率、期望损失和条件平均损失完整报告；
- 保证给付与动态调额两种合同责任分开比较；
- 夫妻最后生存者模型；
- 多随机种子、蒙特卡洛标准误和参数/规格压力；
- 代码、CSV、Markdown 和图片可复现（配对随机种子减少抽样噪声）。

## 12. 仍需访谈确认

- 谁提供长期资金；
- 谁承诺保证给付；
- 谁承担长寿和非追索尾部损失；
- 信托负责财产管理、专户支付、服务对接还是其他环节；
- 房产评估、登记、居住、继承和清算如何执行；
- 动态调额是否能被消费者和监管接受；
- 成本、折价、估值频率等实务参数。

模型的作用是把这些问题量化，不能替代机构决策、法律意见和正式精算定价。
