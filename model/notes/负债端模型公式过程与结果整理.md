# 负债端模型公式、过程与结果整理

本文档整理当前负债端模型的建模目标、核心公式、仿真过程、参数设置和主要结果。对应代码文件为：

```text
liability_model.py
run_liability_scenarios.py
```

对应结果文件为：

```text
outputs/liability_scenario_comparison_official_cl1_2025.csv
outputs/liability_scenario_summary_official_cl1_2025.md
```

## 1. 模型目标

信托以房养老负债端要解决的问题是：

```text
老人每月领取养老金后，信托机构未来形成多少债务？
老人死亡或清算时，房产净变现价值能否覆盖债务？
如果不能覆盖，担保不足损失 shortfall 有多大？
在控制尾部风险和提款中断风险的前提下，老人每月最多能领多少钱？
```

因此，本模型把以下几类不确定性放进同一个蒙特卡洛框架：

- 寿命不确定性：老人何时死亡
- 债务累积不确定性：养老金逐月发放并按利率和成本累积
- 房价不确定性：房产价值未来随机波动
- 利率不确定性：短端利率随机变化
- 风控机制：单向棘轮机制限制提款
- 非追索权风险：房产不足以偿债时产生担保不足损失

## 2. 数据输入

模型当前默认读取官方 CL1 生命表：

```text
official_cl1_life_table_2025.csv
```

该文件由 `extract_official_life_table_2025.py` 从《中国人身保险业经验生命表（2025）》docx 附件中的“养老类业务表男女表（CL1）”抽取得到。原表死亡率单位为 `1/1000`，已转换为小数形式 `qx`。

核心字段包括：

| 字段 | 含义 |
| --- | --- |
| `sex` | 性别，Male / Female |
| `age` | 年龄，50-110 岁 |
| `qx` | 年龄 x 到 x+1 岁之间死亡概率 |
| `px` | 年龄 x 到 x+1 岁之间生存概率 |
| `lx` | 年龄 x 的生存人数 |
| `dx` | 年龄 x 到 x+1 岁之间死亡人数 |
| `ex` | 剩余预期寿命 |
| `mortality_improvement` | 死亡率改善情景，0 为基准，0.15 表示 qx 下调 15% |

后续若取得官方 CL1 生命表，只需要整理成相同字段，即可替换现有 CSV。

## 3. 核心公式

### 3.1 年度死亡概率转月度死亡概率

生命表给出的是年度死亡概率 `qx`，但养老金按月支付，所以模型先转换为月度死亡概率：

```text
q_month(x) = 1 - (1 - qx)^(1/12)
```

其中：

- `qx`：年龄 x 到 x+1 岁之间的年度死亡概率
- `q_month(x)`：该年龄段对应的月度死亡概率

每个月根据 `q_month` 抽样判断老人是否死亡。

### 3.2 利率路径：CIR 模型

短端利率采用 CIR 模型：

```text
dr_t = kappa * (theta - r_t) * dt + sigma_r * sqrt(r_t) * dW_t^r
```

其中：

- `r_t`：t 时点短端利率
- `kappa`：均值回复速度
- `theta`：长期均值
- `sigma_r`：利率波动率
- `dW_t^r`：利率随机扰动

CIR 模型可以避免利率路径大幅变成负数，更适合用于长期负债仿真。

本文参数取值（由官方中债 1 年期国债到期收益率月末序列 2008-2026、219 月，以 AR(1)/OU 校准）：`kappa=0.572`（半衰期约 1.21 年）、`theta=2.22%`、`sigma_r=0.051`，初始短率 `r_0=1.22%`（当前 1Y 现券，2026-03）。房价收益与利率变动的相关系数 ρ 经同一数据实测 ≈0 且统计不显著（|t|<2），故房价冲击与利率冲击独立抽取。

### 3.3 房产价值路径：几何布朗运动

房产价值采用 GBM 模型：

```text
dH_t / H_t = (r_t - q) * dt + sigma_H * dW_t^H
```

离散化后，月度更新为：

```text
H_t = H_{t-1} * exp((r_t - q - 0.5 * sigma_H^2) * dt + sigma_H * sqrt(dt) * Z_t)
```

其中：

- `H_t`：t 时点房产价值
- `r_t`：当期短端利率
- `q`：租售比或连续分红率
- `sigma_H`：房价年化波动率
- `Z_t`：标准正态随机数

### 3.4 债务余额累积

老人每月领取养老金，信托机构形成债权。债务余额按月累积：

```text
D_t = D_{t-1} * (1 + i_t) + draw_t
```

其中：

```text
i_t = (1 + r_t + c)^(1/12) - 1
```

含义：

- `D_t`：t 月末债务余额
- `r_t`：年化利率
- `c`：年化运营成本率
- `i_t`：月度债务累积利率
- `draw_t`：当月实际提款额

如果没有风控限制，`draw_t` 等于设定的月度养老金；如果触发棘轮额度约束，`draw_t` 可能低于设定值。

### 3.5 单向棘轮授信机制

模型设置初始授信额度：

```text
L_0 = LTV * H_0
```

后续每月更新为：

```text
L_t = min(L_{t-1}, LTV * H_t)
```

含义是：

- 房价下跌时，授信额度下降
- 房价上涨时，授信额度不回升
- 授信额度“只降不升”

当月实际提款为：

```text
draw_t = min(PMT, max(L_t - D_t, 0))
```

其中：

- `PMT`：设定的月度养老金
- `L_t - D_t`：当前剩余可提款空间

如果 `draw_t < PMT`，记为提款被截断：

```text
stopped_draw = True
```

### 3.6 清算价值

老人死亡或达到生命表最高年龄时，房产进入清算。考虑流动性折价：

```text
V_T = H_T * (1 - delta)
```

其中：

- `H_T`：清算时房产市场价值
- `delta`：流动性折价率
- `V_T`：房产净变现价值

### 3.7 担保不足损失

非追索权结构下，信托机构不能向老人其他财产或子女追偿。因此风险损失为：

```text
shortfall_T = max(D_T - V_T, 0)
```

其中：

- `D_T`：清算时债务余额
- `V_T`：房产净变现价值

如果 `D_T > V_T`，则产生担保不足损失。

### 3.8 继承人剩余收益

如果房产净变现价值高于债务余额，则剩余价值可返还继承人：

```text
bequest_T = max(V_T - D_T, 0)
```

### 3.9 风险补偿基金费率

按期望短缺计提：

```text
fund_premium_expected = E(shortfall_T) / H_0
```

按 95% 分位短缺计提：

```text
fund_premium_p95 = P95(shortfall_T) / H_0
```

其中 `H_0` 是初始房产价值。

### 3.10 反解最高月领金额

模型使用二分法反解最高月领金额。当前论文主口径采用双重约束：

```text
P95(shortfall_T) / H_0 <= 1%
stopped_draw_probability <= 5%
```

第一条约束控制机构端尾部亏损，第二条约束控制老人端现金流连续性。

加入提款截断概率约束的原因是：单向棘轮机制会限制提款，如果只约束短缺风险，模型可能通过“后期少发钱”来压低亏损，从而高估名义月领金额。因此需要同时控制 `stopped_draw_probability`。

## 4. 仿真过程

每一条蒙特卡洛路径的计算流程如下：

```text
Step 1: 读取生命表，选择性别、起始年龄、死亡率改善情景
Step 2: 将年度死亡概率 qx 转换为月度死亡概率 q_month
Step 3: 初始化房产价值 H_0、债务余额 D_0、授信额度 L_0、利率 r_0
Step 4: 逐月模拟利率路径 r_t
Step 5: 逐月模拟房产价值 H_t
Step 6: 根据单向棘轮机制更新授信额度 L_t
Step 7: 计算当月可提款额度，更新债务余额 D_t
Step 8: 根据月度死亡概率抽样判断老人是否死亡
Step 9: 若死亡，则计算清算价值、shortfall、bequest，并结束该路径
Step 10: 重复大量路径，汇总短缺概率、基金费率、最高月领金额等指标
```

模型输出的核心指标包括：

| 指标 | 含义 |
| --- | --- |
| `monthly_pmt` | 设定或反解得到的月度养老金 |
| `mean_death_age` | 平均死亡年龄 |
| `expected_debt` | 清算时债务余额均值 |
| `expected_total_drawn` | 老人累计实际领取金额均值 |
| `expected_actual_monthly_draw` | 实际月均提款均值 |
| `expected_shortfall` | 期望担保不足损失 |
| `shortfall_probability` | 出现担保不足的概率 |
| `shortfall_p95` | 担保不足损失 95% 分位 |
| `expected_bequest` | 继承人剩余收益均值 |
| `stopped_draw_probability` | 提款被截断概率 |
| `fund_premium_rate_expected` | 期望短缺口径基金费率 |
| `fund_premium_rate_p95` | 95% 短缺口径基金费率 |

## 5. 参数设置

### 5.1 共同参数

| 参数 | 当前取值 | 含义 |
| --- | ---: | --- |
| 起始年龄 | 70 | 默认老人起始年龄 |
| 初始 LTV | 50% | 初始授信额度占房产价值比例 |
| 初始利率 | 2.3% | 初始短端利率 |
| 年运营成本率 | 1.0% | 信托管理、运营等成本 |
| 流动性折价 | 10% | 清算房产时的变现折价 |
| 固定月领测试金额 | 8000 元 | 压力测试用月度养老金 |
| 反解短缺约束 | 1% | `P95(shortfall) / H_0 <= 1%` |
| 反解截断约束 | 5% | `stopped_draw_probability <= 5%` |

### 5.2 房产分层参数

| 场景 | 含义 | 初始房产价值 | 房价波动率 | 租售比 |
| --- | --- | ---: | ---: | ---: |
| `huangpu_small` | 黄浦老破小，70 平米 | 7,070,000 | 11% | 1.86% |
| `minhang_mid` | 闵行改善型，110 平米 | 5,390,000 | 13% | 1.88% |
| `jinshan_small` | 金山老破小，70 平米 | 980,000 | 14% | 2.39% |

### 5.3 生命表情景

| 情景 | 含义 |
| --- | --- |
| `mortality_improvement = 0` | 基准死亡率 |

## 6. 情景分析结果

批量脚本共运行 12 个情景：

```text
3 类房产 * 2 类性别 * 2 类死亡率情景 = 12 个情景
```

每个情景包含两类结果：

1. 固定月领 8000 元压力测试
2. 在双重约束下反解最高月领金额

双重约束为：

```text
P95(shortfall) / H_0 <= 1%
stopped_draw_probability <= 5%
```

## 7. 结果解释

### 7.1 固定月领 8000 元时，低价值或高波动房产风险更高

固定月领 8000 元时：

- 黄浦老破小的短缺概率接近 0，但提款截断概率仍然不低
- 闵行改善型由于波动率高，短缺概率明显上升
- 金山老破小由于初始房产价值低，短缺概率和提款截断概率最高

这说明负债端风险不仅取决于老人寿命，也高度依赖资产端房产价值和波动率。

### 7.2 长寿压力会压低可支付月领金额

对比 `mortality_improvement = 0` 和 `mortality_improvement = 0.15`：

- 死亡率改善后，老人预期寿命延长
- 养老金支付期变长
- 债务余额累积时间变长
- 在同样风险约束下，最高可支付月领金额下降

例如：

```text
minhang_mid / Female:
基准死亡率：约 1559 元
长寿压力：约 1525 元
```

### 7.3 性别差异体现长寿风险差异

女性生命表下，死亡年龄通常更高，因此同一房产场景下，女性对应的可支付月领金额低于男性。

例如：

```text
huangpu_small / 基准死亡率:
Male: 约 5187 元
Female: 约 4783 元
```

### 7.4 加入提款截断约束后，结果更审慎

如果只控制短缺风险，模型可能通过棘轮机制减少后续提款，从而降低机构亏损，但这会影响老人现金流。因此当前主口径同时约束：

```text
机构端：P95 短缺率不超过 1%
老人端：提款截断概率不超过 5%
```

在这个口径下，反解出的月领金额可以更准确理解为“具有较高持续支付可行性”的月领金额，而不是单纯的名义额度。

### 7.5 当前双重约束下的关键结论

在 `P95(shortfall) / H_0 <= 1%` 且 `stopped_draw_probability <= 5%` 下：

- 最高可支付月领金额最高的情景是 `huangpu_small / Male / mortality_improvement = 0`，约 5187 元
- 最高可支付月领金额最低的情景是 `jinshan_small / Female / mortality_improvement = 0.15`，约 568 元
- 区位、初始房产价值、房价波动率、性别和长寿压力都会显著影响负债端定价
- 对低价值房产，负债端主要约束往往不是最终 shortfall，而是提款连续性不足

## 8. 可写入论文的表述

本文在负债端采用生命表驱动的随机停止时点模型，将老人死亡时间建模为由年度死亡概率 `qx` 推导出的月度死亡过程。养老金债务余额按月发放并随短端利率和运营成本复利累积，房产价值则通过几何布朗运动刻画其未来不确定性。模型进一步引入单向棘轮机制，使授信额度随房产评估价值下调而下调、但不随房价上涨而上调，从而限制房地产下行周期中的债务膨胀。

在非追索权结构下，清算时若债务余额超过房产净变现价值，其差额即为担保不足损失。模型以 `shortfall = max(D_T - V_T, 0)` 作为风险补偿基金计提基础，同时以 `bequest = max(V_T - D_T, 0)` 衡量可返还继承人的剩余权益。为避免单纯依靠棘轮限额降低机构亏损而牺牲老人现金流，本文采用双重风险约束反解月度养老金，即要求 `P95(shortfall) / H_0 <= 1%` 且提款截断概率不超过 5%。仿真结果表明，房产初始价值、房价波动率、性别和长寿压力均会显著影响可支付月领金额，其中远郊低价值房产和女性长寿压力情景下的负债端约束最为严格。
