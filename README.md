## 模型要点（当前权威口径）

- **P 测度**蒙特卡洛风险与支付能力模型（非 Q 测度公允价值）。
- 死亡率：官方《中国人身保险业经验生命表（2025）》养老类业务表 **CL1**；终端龄 105 岁 qx=1.0 标准闭合。
- 房价：GBM 骨架 + **两成分正态混合肥尾**（5% 概率 × 3 倍标准差，按精确矩母函数修正对数增长；已替代 Student-t）；分区波动率 黄浦11%/闵行13%/金山14%；独立漂移 g_H^P=0%（**已作废 $(r-q)$ 风险中性漂移，勿改回，理由见 [`docs/决策记录.md`](docs/决策记录.md)**）。
- 利率：**CIR**（κ=0.572、θ=2.22%、σ_r=0.051、r₀=1.22%，官方中债 1Y 校准）；房价×利率冲击独立（实测 ρ≈0）。
- 两类合同：**保证给付年金（主模型，停付=0）** 与 **动态调额提款（扩展，阈值 70%+保底 70% 棘轮）**。
- 反解约束：**ES95/H0 ≤ 1%**（VaR95/P95 在损失概率<5% 时恒为 0、是空约束）。
- **可复现性**：所有表对同一画像用 `profile_seed` 权威种子 + 统一 4000 路径 → 同画像跨表数字完全一致。
- 主表（70 岁 LTV50% 保证给付月领）：黄浦 2,585–3,232 元、闵行 1,617–1,981 元、金山 259–269 元。

## 如何复现模型

见 [`model/README.md`](model/README.md)。一句话：装 `model/CL1模型/requirements.txt`（Python ≥ 3.9），在 `model/CL1模型/` 目录下依次跑 `scripts/` 下 4 个 run 脚本，结果写回 `outputs/`。

## 数据来源与不入仓说明（做 PPT 取数用）

**为什么部分数据不入库**：① **体积**——区级房价 xlsx、70 城指数、340 城面板等为数十万行的第三方授权数据，会让仓库臃肿、clone 变慢；② **版权与许可**——CSMAR / 马克数据网 / 安居客 / 中国房价行情网 等为**付费或受版权保护**的数据，公开仓库再分发违反其许可；③ **可复现性不受影响**——模型只依赖**处理后**的派生量（分区 σ、q、ψ、CIR 参数、权威种子下的输出表），这些已随仓库给出，团队据此即可复现与做图。
