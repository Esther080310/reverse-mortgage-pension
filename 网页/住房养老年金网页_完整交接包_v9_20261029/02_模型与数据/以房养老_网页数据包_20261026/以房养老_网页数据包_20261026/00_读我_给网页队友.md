## 一、三条铁律（违反即返工）

1. **屏幕上每个数字，只能来自 `tables/` 里的表，或调用 `model_api/` 实算。** 禁止前端自创公式、线性缩放、跨表插值/拼接。
2. **同一画像只能有一个答案。** 所有表与 model_api 用同一权威种子（profile_seed）+4000 路径，天然一致；若你对出两个数，说明你绕过了它们。
3. **全程显著标注"研究演示，非正式报价"。** 这是大创研究原型；ES95 不是保费/监管资本；VaR95=0 不代表零风险。

## 三、model_api 用法（定制测算的唯一正确姿势）

```bash
cd model_api
pip install -r requirements.txt        # numpy/pandas（Python>=3.9）
python model_api.py --segment huangpu_small --sex Male --age 70
python model_api.py --segment minhang_mid --sex Female --age 65 --property-value 5000000 --ltv 0.5 --policy adjustable_draw
```
返回 JSON：`monthly_pmt / shortfall_probability / shortfall_es95_rate / shortfall_var95_rate / stopped_draw_probability / expected_actual_monthly_draw / mean_settlement_age / seed / n_sims`。
- 任意 性别/年龄/房价/LTV/漂移/合同类型 都可算（后端每次请求调一次，约数秒）；**不要**在前端算。
- `--segment` 决定 σ/折价/租金参数（黄浦/闵行/金山三档）；自定义 `--property-value` 只改房价、风险参数仍随 segment。若要更多分区，等组长扩区参数表（尚未产出）。

## 四、自测（必做）：用 fixtures 验收你的实现

对 `tables/validation_fixtures.csv` 每一行，用同样的输入调 `model_api`（或查你的后端缓存），断言：
- `monthly_pmt` 与 `expected_monthly_pmt` 相差 **≤5 元**（二分容差）；
- `shortfall_es95_rate` 与 `expected_es95_rate` 相差 **≤0.0005**；
- 保证给付行 `stopped_draw_probability` 必须为 **0**。
任何一条对不上 = 你的链路算错了，修到全绿再上线。

## 五、账户页（逐月）怎么用 trajectories

`monthly_central_trajectories.csv` 每行=某画像某月：`house_value / rate / guaranteed_draw / guaranteed_debt / guaranteed_debt_to_house / guaranteed_exit_net / adjustable_draw / adjustable_debt / adjustable_credit_limit / ratchet_triggered`。
- 它是**模型参数推导的中心/期望轨迹**（每月到账=主表反解 PMT），用于"签约后家庭账户"逐月演示；**页面须注明"中心情景演示，非承诺、非真实流水"**。
- 压力/崩盘情形用 `liability_house_crisis_ratchet_path.csv`（闵行·固定8000·第10年跌30% 的确定性情景）。
