# “以房养老信托”综合数字化管理平台架构设计与原型规划

为确保“保险年金险模式（方案一）”的精算风控与“养老服务信托模式（方案二）”的资源调度能够无缝落地，本项目设计了统一的综合数字化管理平台。该平台作为底层基建，通过“三个核心中台 + 两个前端入口”的架构，实现资产风控、资金结算与代际传承的全链路数字化。

## 一、 系统逻辑架构（三层中台）

### 1. 资产风控中台（双模式的共同底座）
*   **API 自动估值模块**：对接中国房价行情网（CREIS）等权威接口，按月自动抓取底层房产的最新市场评估净值（$V_t$）。
*   **动态棘轮监控引擎（方案一核心）**：实时计算当期理论授信额度（$LTV \cdot H_t$）。当房产价值暴跌触碰红线时，系统自动触发熔断预警，冻结下月新增提款额度，实现风控参数的自动化执行。
*   **生命表健康与久期监测模块**：与社保/公安系统数据打通，确认老人当月生存状态；同时内嵌《2025官方CL1生命表》，动态测算信托剩余预期久期与长寿风险敞口。

### 2. 资金清结算中台（双模式自适应引擎）
*   **【配置 A：现金年金模式】（方案一）**：
    *   每月定时从信托资金池向老人的指定银行账户划拨定额养老金（如黄浦老王的 5,187 元）。
    *   后台自动执行复利计算：$D_t = D_{t-1} \cdot (1 + r_t + c) + draw_t$，实时更新总债务账本。
*   **【配置 B：服务抵扣模式】（方案二）**：
    *   资金不经过老人，而是直接向合作的康养机构对公账户进行结算。
    *   系统支持“租金冲抵”的轧差结算逻辑：若房产产生租金收益，优先抵扣当月护理账单；不足部分再计入信托负债。

### 3. 契约与传承中台（化解代际阻力）
*   **“孰低法”赎回报价器**：在老人身故触发清算时，系统自动调取累计债务（$D_T$）和当期房产净值（$V_T$），自动执行 $\min(D_T, V_T)$ 公式计算最低赎回价格，并向法定继承人一键发送“优先赎回邀约”。
*   **JHF 兜底理赔接口**：若子女放弃赎回且房屋流拍导致资不抵债，系统自动生成《预期担保不足损失（ES）测算报告》，通过 API 向政府背景的风险补偿基金（类似 JHF）发起标准化的理赔申请。

## 二、 交互原型图规划（两个前端入口）

针对不同用户群体的核心诉求，平台划分为“机构端（PC网页）”与“家庭端（微信小程序）”，原型设计重点展示以下核心页面：

### 1. 机构端（信托经理与风控官看板）
*   **【全盘风险驾驶舱（Dashboard）】**：
    *   **核心指标**：当前资金池总规模、总体贷款价值比（LTV）、长寿风险敞口指标。
    *   **可视化图表**：实时展示类似“棘轮机制应对房价崩盘的压力测试图”的动态曲线，红线标注警戒阈值。
*   **【资产异常预警列表】**：
    *   列表展示所有触发“棘轮降额”或“资不抵债预警”的单体房产项目，支持一键生成风险处置工单。

### 2. 家庭端（老人与子女共享的小程序）
*   **【首页：资产与权益看板】**：
    *   大字版UI设计，直观展示：本月养老金是否已到账 / 养老院账单是否已结清。
    *   展示房屋当前市场估值曲线与累计债务曲线的对比（增加透明度）。
*   **【契约与传承页面】**：
    *   面向子女展示：老人近期的健康/护理报告汇总。
    *   **核心功能（亮点）**：实时显示的“当前赎回估价”，让子女清晰知晓随时买回祖宅所需的资金代价，彻底消除信息差与继承恐慌。
