## 二、第 1 项展开：为什么必须从 $(r-q)$ 改成 $g_H^P$

这是最容易被接手者"好心改回去"的一处，因为 $(r-q)$ 看起来才是标准无套利设定。完整理由四条：

1. **测度混用**。$(r-q)$ 是**风险中性测度 Q** 下的估值关系；而本模型输出的 ES95、停付概率、损失概率全是**物理测度 P** 的真实世界风险指标。用 Q 测度的漂移去驱动 P 测度的模拟，数学上不自洽。
2. **口径错配**。$\sigma_H$ 取自区级**房价价格指数**（马克网），价格指数的漂移本就不该再扣净租金 $q$；只有"价格+租金"的总回报才需要扣净租金。
3. **现金流归属错**。老人自住产生的**居住收益不是机构的实收现金**，不能计入机构现金流。机构能拿到的只有清算时的房产变现值。
4. **方向反了**。$(r-q)$ 会让"加息→房价涨越快→授信越高→老人领得越多"，与"利率升→机构风险升"的经营逻辑相反；改用独立 $g_H^P$ 后，债务按 $(r+c)$ 累积而房价不随 $r$ 涨，方向自然纠正。

**两个常见的反驳，都已被否：**

- **"实测 $\rho\approx0$，所以冲击独立，那漂移耦合也无妨"** —— 不成立。$\rho$ 描述的是**同一时点两个冲击的相关性**，漂移描述的是**给定状态下的条件期望**，两者互不决定，$\rho\approx0$ 不能给 $(r-q)$ 背书。
- **"HECM 里利率高→可贷额度低，所以 PMT 必须随利率降"** —— 不能直接套用。HECM 那条规律来自其**债务累积 + 保障成本 + 额度规则**的组合；本项目初始 LTV 固定 50%、且用随房价下调的单向棘轮，合同机制不同，反直觉的方向本身不构成模型错误的证据。

**其他被否的替代方案：**

- $g_H^P = r + \pi_H - q$（固定风险溢价）：加息仍会机械抬高房价漂移，未真正解除利率耦合。
- 保留 $(r-q)$ 只改写叙述（"忠于当前模型"）：测度混用的硬伤仍在。

**代码位置**：`model/CL1模型/scripts/liability_model.py` 中 `drift_mode` 与 `g_H_P` 两个字段（字段旁已加冻结注释）。`drift_mode="rq"` 仅保留为**对照开关**，可跑对照、**不可**作为主模型产出对外结论。

## 三、第 2、3 项补充

- **Student-t 为什么不能用**：把标准化 t 直接塞进 $H_t=H_0e^{(g-\frac12\sigma^2)t+\sigma W_t}$ 时，$-\frac12\sigma^2$ 这一项来自正态情形的矩母函数 $E[e^{\sigma Z}]=e^{\sigma^2/2}$；t 分布不存在矩母函数，故该修正**无定义**，模拟出来的期望增长与声称的漂移不一致。正态混合有闭式矩母函数，且仍保留单位方差与肥尾。
- **为什么用 ES95 不用 VaR95**：本项目主情景的损失（房产变现值 < 债务）概率长期低于 5%，此时 95% 分位数**恒为 0**，"P95 ≤ 1%" 这条约束永远满足，等于没有约束。ES95 取最差 5% 路径的平均损失，才是有效尾部约束。
